# GCP HCP E2E demo (Slidev)

Five-slide lightning talk based on the final [team cheat sheet](https://redhat.atlassian.net/wiki/spaces/GCP/pages/506888659/GCP+HCP+E2E+Jobs+Team+Cheat+Sheet). The detailed talking points and source links are in Slidev presenter notes.

## Present

```bash
npm ci
npm run dev
```

Open the URL printed by Slidev. Press `F` for full screen or use Slidev's presenter view to see notes.

To make a static web build:

```bash
npm run build
```

The deck uses Red Hat red, neutral grays, and the Red Hat font family. It uses locally installed Red Hat fonts when available and falls back to system sans-serif. The live job-history links on slide 4 are intentional: green/red results can change before the demo.
